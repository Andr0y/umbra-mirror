# Data layout

Large EEG→EMG datasets and model checkpoints are **not** committed to Git. Place them locally under the paths below (see `.gitignore`).

## Expected layout

```
data/
├── eeg_emg/                    # Paired EEG+EMG archives (.npz)
│   ├── dataset_subject_1.npz   # Example single-subject set
│   └── dataset_augmented.npz   # Optional augmented set (larger)
├── eeg_emg_quality_reports/    # Generated by dashboard (optional)
├── eeg_emg_comparison_reports/
└── eeg_emg_hardware_reports/

src/eeg_emg/
├── eeg2emg_best.pth            # Primary checkpoint for the dashboard
└── eeg2emg_baseline.pth        # Optional comparison baseline
```

## Obtaining data

1. **From raw CSV/MAT trials** — use your institution’s EEG/EMG export, then convert to `.npz` with aligned `eeg` and `emg` arrays (see `src/eeg_emg/convert_eeg_emg_to_npz.py` as a starting point; adapt paths to your machine).
2. **Pre-built `.npz`** — if your team shares prepared files, copy them into `data/eeg_emg/`.

Each `.npz` should contain at least two arrays (keys are matched case-insensitively), e.g. `eeg` and `emg`, with compatible time dimensions.

## Training a checkpoint

From the repository root:

```bash
python -m src.eeg_emg.eeg2emg_run \
  --data_path data/eeg_emg/dataset_subject_1.npz \
  --normalize \
  --save_path src/eeg_emg/eeg2emg_best.pth
```

Or: `make train-eeg2emg` (uses `dataset_subject_1.npz` by default).

## Dashboard uploads

Temporary uploads land in `data/eeg_emg/_uploads/` (gitignored). Size limits: `UMBRA_MAX_NPZ_UPLOAD_MB`, `UMBRA_MAX_PTH_UPLOAD_MB` (see root `README.md`).
